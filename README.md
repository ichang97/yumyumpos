# YumYum POS

ระบบ POS ขายหน้าร้านสำหรับร้านอาหารขนาดเล็ก (Counter POS + QR Self-Order + Kitchen Kanban + เสียงอ่านคิวภาษาไทย) ออกแบบให้ใช้งานสะดวกทั้งบนมือถือ iPad และ Desktop รันบน Cloudflare Workers และ Cloudflare D1

- ระบบพนักงาน / ครัว / จัดการร้าน: https://yumyum-pos.mrkwttx.workers.dev
- หน้าลูกค้าสแกนสั่งอาหารเอง: https://yumyum-pos.mrkwttx.workers.dev/order

---

## ฟีเจอร์หลัก

### 1. ขายหน้าร้าน (Counter POS)
- รองรับทั้ง **ทานที่ร้าน** และ **สั่งกลับบ้าน** พร้อมระบุชื่อลูกค้า (ไม่บังคับ)
- ระบบกลุ่มตัวเลือก (Single / Multiple select, บังคับ / ไม่บังคับ) และเมนูที่คิดราคาตามตัวเลือกเสริม
- รองรับการเพิ่มเมนูเองหน้าร้าน (Custom Menu) และหมายเหตุรายจาน
- รันเลขคิวรายวัน (`Q001`, `Q002`, ...) รีเซ็ตอัตโนมัติทุกวันตามเวลาไทย (`Asia/Bangkok`)
- พิมพ์บัตรคิว, ใบครัว และใบเสร็จรับเงิน

### 2. ลูกค้าสแกน QR สั่งอาหารเอง (`/order`)
- ปุ่ม **`QR ลูกค้า`** บนแถบเมนูสำหรับเปิดดูและพิมพ์ป้าย QR หน้าร้านได้ทันที
- ลูกค้าเลือกทานที่ร้าน/กลับบ้าน สั่งอาหาร เลือกวิธีจ่ายเงิน และติดตามสถานะคิวแบบเรียลไทม์ (อัปเดตอัตโนมัติทุก 5 วินาที)
- จำคิวของวันนี้ไว้ใน `localStorage` บนมือถือลูกค้า และเคลียร์คิวเก่าที่ถูกลบออกจากระบบให้อัตโนมัติ

### 3. ชำระเงินก่อนส่งเข้าครัว (เงินสด & สแกน QR Code)
- รองรับทั้ง **เงินสด** (คำนวณเงินทอนอัตโนมัติ พร้อมปุ่มลัดรับเงิน) และ **สแกน QR Code**
- อัปโหลดรูป QR ชำระเงินของร้านเองได้ (เก็บใน D1 และย่อรูปอัตโนมัติ) หรือกรอกเลขพร้อมเพย์สำรองให้ระบบสร้าง EMVCo QR ล็อกยอดอัตโนมัติ
- บังคับ **ชำระเงินก่อนเข้าครัว**: บิลที่ยังไม่ชำระเงินจะรออยู่ที่แท็บ **`บิล / คิว`** (`ยังไม่เข้าครัว`) และเมื่อพนักงานกดยืนยัน **`ชำระแล้ว`** คิวจึงถูกส่งเข้าช่อง **`รอทำ`** ในครัว

### 4. กระดานครัว (Kitchen Kanban) + เสียงอ่านคิวภาษาไทย
- แบ่ง 3 ช่องดูง่าย: **`รอทำ`** → **`กำลังทำ`** → **`เสร็จแล้ว / รอรับ`** (เรียงคิวตามเวลาที่ชำระเงินก่อน-หลัง)
- อ่านออกเสียงเมนูภาษาไทยผ่าน Web Speech API (`th-TH`) ตามคิว:
  - **ครัวว่าง**: เมื่อมีคิวใหม่เข้ามา ให้อ่านคิวแรกทันที
  - **มีคิวซ้อน**: ไม่รบกวนระหว่างทำ จะอ่านคิวรอทำถัดไปเมื่อคิวที่ทำอยู่เสร็จแล้ว (`ready`)
- ปรับความเร็วเสียงอ่านได้ (`0.9x` – `2.0x`, ค่าเริ่มต้น `1.15x`) และกดอ่านซ้ำรายใบคิวได้ตลอดเวลา

### 5. โหมด Admin (แตะโลโก้ `YumYum POS` 5 ครั้ง)
- จัดการหมวดหมู่ เมนูอาหาร (เปิด-ปิดขายชั่วคราว) และกลุ่มตัวเลือก
- ตั้งค่าวิธีชำระเงิน อัปโหลด/เปลี่ยน/ลบรูป QR ของร้าน และเลขพร้อมเพย์
- ดูรายงานสรุปยอดขาย แยกเงินสด/โอน และแยกช่องทางหน้าร้าน/QR
- ปุ่ม **`ล้างบิลและคิวทั้งหมด (รีเซ็ตเป็น Q001)`** โดยไม่ลบเมนู หมวดหมู่ และรูป QR ของร้าน

### 6. ความปลอดภัย (Cloudflare Access & API Validation)
- หน้าพนักงานและ `/api/*` ป้องกันด้วย Cloudflare Access พร้อมเปิด Public Override เฉพาะหน้าสั่งอาหารลูกค้า (`/order`, `/assets/*`, `/api/public/*`)
- ตั้ง Security Headers (`Content-Security-Policy` ไม่อนุญาตสคริปต์/สไตล์ภายนอก), ตรวจสอบสิทธิ์/ความถูกต้องฝั่งเซิร์ฟเวอร์ทุกคำขอ และตรวจ Magic Bytes ของไฟล์รูปที่อัปโหลด

## Tech Stack

- **Frontend**: Vue 3, Vite 6, Tailwind CSS v4, Lucide Icons, Noto Sans Thai (`@fontsource/noto-sans-thai`), `qrcode`
- **Backend & Database**: Hono, Cloudflare Workers + Static Assets, Cloudflare D1 (SQLite)

---

## การพัฒนาและทดสอบในเครื่อง

> ต้องใช้ Node.js `>= 22.12.0` สำหรับ Wrangler 4

1. ติดตั้ง dependencies:
   ```bash
   npm install
   ```
2. รัน D1 migrations ในเครื่อง:
   ```bash
   npm run db:migrate:local
   ```
3. รันโหมดพัฒนา:
   ```bash
   npm run dev
   ```
4. Build สำหรับ Production และรันชุดทดสอบอัตโนมัติ (`scripts/verify-worker.js`):
   ```bash
   npm run build
   npm test
   ```
